# CENA
A CENA conecta artistas, diretores, produtores e companhias teatrais por meio de uma experiência interativa de descoberta e casting. Com perfis artísticos, audições, candidaturas e Matches, busca democratizar o acesso às oportunidades nas artes cênicas, aproximando talentos de produções e novas histórias. Seu talento merece entrar em cena.
